1. ОБЩАЯ АРХИТЕКТУРА И ИНФРАСТРУКТУРА
Система представляет собой автономный двух-агентный конвейер производство контента, управляемый через n8n (оркестратор), интегрированный с SPA-админкой, внешними API (Claude, Kie, ElevenLabs) и развернутый на серверной инфраструктуре под управлением Coolify.
1.1. Серверная инфраструктура (Coolify on Cloud VPS)

* Хостинг / Сервер: Выделенный Cloud VPS (рег ру).
* Конфигурация: 4 vCPU / 8 GB RAM / 60+ GB NVMe SSD.
* Панель управления: Coolify (Open-Source PaaS).
* Разворачиваемые сервисы внутри Coolify:
   1. `albacreation.ru` — Публичный лендинг компании.
   2. `app.albacreation.ru` — SPA-админка
   3. `n8n.albacreation.ru` — Визуальный бэкенд и оркестратор ИИ-агентов.
   4. `PostgreSQL` — Единая база данных для хранения идей, логов и аналитики трат.

5. МОДУЛЬ УЧЕТА РАСХОДОВ (COST & TOKEN TRACKER)
5.1. Расчет стоимости операций
После каждого прогона n8n извлекает объект `usage` и логирует расходы в PostgreSQL по формуле:
\text{Total Cost} = (\text{Tokens}_{\text{in}} \times P_{\text{in}}) + (\text{Tokens}_{\text{out}} \times P_{\text{out}}) + \text{Cost}_{\text{Kie}} + \text{Cost}_{\text{ElevenLabs}}

* Daily Cap (Лимит бюджета): Автоматическая отсечка при достижении $2.00/день (при превышении создаются только тексты без рендеринга видео).

5.2. Схема базы данных (`agent_expenses`)

* `id` (SERIAL PRIMARY KEY)
* `timestamp` (TIMESTAMP DEFAULT NOW())
* `agent_name` ("RESEARCHER" | "GENERATOR")
* `model_used` (VARCHAR)
* `input_tokens` (INT), `output_tokens` (INT), `cached_tokens` (INT)
* `kie_credits_spent` (NUMERIC)
* `total_usd` (NUMERIC)
