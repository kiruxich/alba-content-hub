Built a minimal but complete `content_rubrics` feature end-to-end.

**Backend** (`server/routes/contentRubrics.js`, new) — CRUD mirroring `mediaAssets.js`'s style: `GET /` (active-only by default, `?all=1` for everything), `POST /`, `PUT /:id` (including `isActive` toggle), `DELETE /:id` (hard delete). Mounted at `/api/content-rubrics` in `server/app.js`.

**Seed data** (`server/db.js`) — 3 guarded (`INSERT OR IGNORE`, fixed ids) starter rubrics: "Кейс недели" (BOFU), "Разбор ошибки клиента" (MOFU), "Технический лайфхак" (TOFU), each with a 3-step `structure_template` shaped like the businessProblem/technicalSolution/businessResult fields `editorValidation.js` checks.

**Frontend — placement decision**: embedded the rubrics list/add/edit/delete sub-section inside the existing "Настройки агентов" tab (`view-agentsettings`), below the Generator prompt. Chose this over a new tab because rubrics are content-authoring configuration alongside tone-of-voice/formula/prompt already there, and the view wasn't dense enough to justify a 14th tab. Built with existing CSS classes only (`parser-niches-grid`/`parser-niche-card`, `format-tag`, `group-chip`, `edit-btn`/`delete-btn`) — no new styles needed.

**Idea modal picker** — added a `&lt;select id="edit-idea-rubric-input"&gt;` in `#edit-idea-overlay` (simple dropdown, as the task allowed, rather than a full cover-picker-style overlay since rubrics have no media to preview). Saves to the idea's existing `rubricId` field. Handles the edge case where an idea references a since-deleted/deactivated rubric by still showing it in the dropdown, labeled "(неактивна)" or "рубрика удалена".
