No data in window →

Data present →

```json
  "underperformers": [ ... same shape, bottom 5 ],
  "rubricPerformance": [{ "rubricId", "rubricName", "count", "avgViews", "avgSaves" }]
}
```

Important caveat I flagged in code and docs: `ideas` has **no persisted `product_id` column**, so `byProduct` is best-effort — it only picks up `agentMeta.targetProduct`/`target_product` when present, which today is essentially nothing (Generator's `agentMeta` currently only carries `sourceUrl`). ### `POST /api/insights/conclusions`
Body: `{ summary: string (required), recommendations: array (optional) }` → stores into `agent_runs` with `agent_name: 'insights'`, `log = summary`, `brief_json = JSON.stringify({summary, recommendations, generatedAt})`. Missing summary → `400`. Success → `201 { ok: true, runDate }`.

### `GET /api/insights/latest`
